# Линейная алгебра — подготовка к КР 1

188 задач из списка к контрольной, разложенных по темам: системы линейных уравнений, действия с матрицами, перестановки, определители.

- **Сайт:** `index.html` — условия задач; ответы и решения скрыты под кнопками «Ответ» и «Решение».
- **PDF:** `kr1.pdf` — условия и ответы (без решений).

Источники: И. В. Проскуряков, «Сборник задач по линейной алгебре» (П); «Сборник задач по алгебре» под ред. А. И. Кострикина (К). Ответы проверены пересчётом, найденные опечатки задачников отмечены примечаниями.
